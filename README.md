# Ясли 1.1.6

Семейная игра о католическом Рождестве. Один телефон на всех: ребёнку — короткий вопрос, взрослому — вопрос по Евангелию и катехизису. История идёт от Благовещения к яслям и Богоявлению.

Автор: Ермаков Алексей Сергеевич, alexey@ermakov-mail.ru

## Версия

Номер один на всё приложение: `src/game/version.ts`. Он же написан на главном экране и на странице «Как играть».

История: [CHANGELOG.md](CHANGELOG.md).

Каталог: [versions.xml](versions.xml).

Оба пакета — версия 1.1.6, код 116, minSdk 24, targetSdk 35. Разрешения ставить обновления самому нет: новую версию ставит RuStore или магазин YaOS. Интернета у приложения нет.

Язык берётся из системы. Если перевода нет, открывается английский. В углу экрана — смена языка и выключатель музыки. Языки: русский, белорусский, украинский, итальянский, английский, французский, немецкий, испанский, португальский, польский.

На телевизоре стрелки пульта переходят к соседней кнопке, OK выбирает, «Назад» возвращает на предыдущий экран и с главного закрывает игру. Алиса нажимает кнопку по её словам: «Семейный путь», «Играть одному», «Как играть». Имя у поля можно сказать кнопкой «Сказать имя».

Пользовательское соглашение: [docs/eula.html](docs/eula.html). Политика конфиденциальности: [docs/privacy.html](docs/privacy.html).

Подпись одна на оба пакета, `CN=Yasli`. Отпечаток SHA-256: `9A8E25DCDEA8E066F2326087E25E3EC3939D455D9CDA70016EC5C74DA04AF3AB`. Схемы v1, v2 и v3. Сам ключ в репозиторий не входит.

Сборка: `sh scripts/build-android.sh`. Нужны Java 17 и Android SDK в `.android-sdk` (platform 35, build-tools 35).

## Как устроена игра

- Короткий путь — шесть стоянок.
- Вечерний путь — двенадцать, от Адвента до Богоявления, со стоянки «Слава в вышних», которую говорят вместе.
- Ошибка не обрывает рассказ: после ответа всегда есть пояснение.
- Счёт звёзд остаётся на этом устройстве.

Игра для домашнего вечера. Она не заменяет Мессу и не является приходским катехизисом.
