## Текст для карточки

Название: Ясли

Кратко: Семейная игра о католическом Рождестве. Один телефон, дети и взрослые.

Полное:

Ясли — домашняя игра о католическом Рождестве. Один телефон на всю семью. Ребёнку короткие вопросы про ясли, звезду и имя. Взрослому — календарь, Непорочное Зачатие, Николай и Санта, смысл даров.

Короткий путь — шесть стоянок, от Благовещения до Богоявления. Вечерний — двенадцать, от Адвента до Богоявления. После ответа всегда есть пояснение. В конце — стих из Евангелия от Луки и короткая молитва.

Игра работает без интернета. Есть русский, белорусский, украинский, итальянский, английский, французский, немецкий, испанский, португальский и польский. С запуска играет рождественская музыка, её можно выключить.

На телевизоре кнопки нажимаются пультом. Алиса нажимает кнопку по её словам. Имя можно сказать вслух.

Это домашний вечер, не замена Мессе и не приходской катехизис.

Возраст: 6+
Категория: игры для семьи
Почта: alexey@ermakov-mail.ru

Для навыка в Диалогах активационные фразы: «запусти ясли», «запусти навык ясли».
